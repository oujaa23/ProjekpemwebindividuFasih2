# RuangNada
RuangNada adalah website playlist musik yang dirancang sebagai pendamping belajar. Website ini membantu pengguna memilih musik sesuai genre, mengatur waktu belajar, dan mencatat tugas.

## Fitur Utama
- Navigasi Beranda, Playlist, dan Ruang Fokus.
- Pencarian, filter, dan pengurutan lagu.
- Pemutar musik dan playlist.
- Track Timer 25 menit dan istirahat 5 menit.
- Track Tugas untuk menambahkan tugas.
- Tampilan responsif untuk desktop dan mobile.

## Teknologi
- HTML5
- CSS3
- JavaScript
- Figma
- GitHub Pages

JavaScript digunakan untuk manipulasi DOM, event handling, pengelolaan data lagu menggunakan Array of Objects, timer, playlist, dan daftar tugas.
